# tasks/

Where PRDs and task lists live. One PRD per feature.

## Convention

- `prd-<feature-name>.md` — the spec, generated by `pr_flow/create-prd.mdc`
- `tasks-prd-<feature-name>.md` — the task list, generated by `pr_flow/generate-tasks.mdc`

## Workflow

1. Open Claude Code in this repo.
2. Say: *"I want to add [feature]. Use `pr_flow/create-prd.mdc`."*
3. Claude asks clarifying questions. Answer with letters/numbers.
4. PRD lands in this folder.
5. Say: *"Generate tasks for `prd-<feature-name>.md` using `pr_flow/generate-tasks.mdc`."*
6. Claude generates parent tasks. Reply `go` for sub-tasks.
7. Say: *"Process the task list using `pr_flow/process-task-list.mdc`."*
8. Reply `next` between each sub-task.

See `prd-example.md` in this folder for a worked example.
