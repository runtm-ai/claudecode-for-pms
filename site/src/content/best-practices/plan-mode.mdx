The default Claude Code session edits as it thinks. That works for one-file fixes. For anything that touches three files or more, plan mode is the difference between a clean PR and an afternoon of cleanup.

### The pattern

1. Toggle plan mode (Shift+Tab in the CLI; toggle in the UI).
2. Ask for the change. Claude returns a plan instead of edits.
3. Read it. Push back where it picked the wrong scope. Ask for alternatives.
4. Approve. Implementation now runs against a contract you both agreed to.

### Why it works

A plan is cheap to revise. A diff is expensive. By the time you see the diff, the model has committed to a thousand small decisions and rolling back is a negotiation. Plan mode lets you negotiate while the cost is still words.

### What good plans contain

- The files that will change.
- The order of operations.
- The trade-offs the model considered and rejected — read these; they're where you'll catch a bad assumption.
- A list of what's out of scope for this change.
