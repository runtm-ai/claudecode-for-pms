Owen Williams (Stripe) puts it bluntly on *How I AI*: the design system has to be a skill, or every page comes back indigo.

### The pattern

`skills/your-brand/SKILL.md` is the full design system, expressed in the same SKILL.md shape as every other skill in the repo. The model auto-loads it whenever it's generating a UI, a landing page, a deck slide, a release note — anything a customer will see.

### What goes in it

- **Color tokens** — primary, soft, dark, neutrals, status. No "any indigo will do".
- **Typography** — size / weight / letter-spacing / line-height per role. System fonts unless you have a tested webfont reason.
- **Voice in one sentence** plus banned words.
- **Surface treatments** — cards, shadows, radii. One block of CSS or one tsx snippet.
- **Pre-ship checklist** — six bullets, runs before every PR.

### Why this beats a Figma library

A Figma library is something the model can't read. A `SKILL.md` is something it can. Both should exist; the skill is the one that changes output.
