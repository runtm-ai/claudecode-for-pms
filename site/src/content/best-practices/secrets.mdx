The fastest way to ruin a Friday is realizing a GitHub token is in your last commit.

### The setup that works

- `.env.example` — the template. Lives in the repo. Contains keys, never values.
- `.env` — your actual values. Listed in `.gitignore` from day one.
- `mcp.json.example` — the MCP config template. Values come from `${ENV_VAR}` references that resolve from your shell, not from a checked-in `.mcp.json`.

### When the model asks for a token

It shouldn't. If Claude asks you to paste a token into chat, that token is now in the conversation history and any future tool that processes the transcript. Refuse. Set it in your shell environment instead and let the MCP server read it.

### The recovery

If you commit a secret: rotate the secret first, then rewrite history second. The order matters. A revoked token in a public commit is harmless; a leaked active token isn't, even after you force-push.
