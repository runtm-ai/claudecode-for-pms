2026-05-26v0.1.0

First release — the cloneable repo and the site

The first public cut. Six skills, ten practices, the pr_flow rules, and a site to read it all from.

What ships in the repo

  • CLAUDE.md, DESIGN.md — the two files Claude reads first.
  • pr_flow/ — three rules: create-prd, generate-tasks, process-task-list.
  • skills/ — six starter skills: writing-prds, writing-release-notes, writing-stakeholder-updates, synthesizing-user-research, prioritizing-features, your-brand.
  • mcp.json.example — config template for GitHub / Linear / Notion / PostHog MCPs.

What ships on the site

  • Ten best-practice pages.
  • A skills index with 32 curated skills (6 ship in this repo; 26 vetted from anthropics/knowledge-work-plugins, phuryn/pm-skills, deanpeters/Product-Manager-Skills, and typeui.sh).
  • A templates page that renders the repo files in place.
  • A resources page with the reading list we synthesized from.

What’s next

More skills, more practice pages, a stronger contribute flow. PRs welcome.
